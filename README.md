# Study Buddy AI

Create a professional AI-powered general education chatbot for my website called “Study Assistant”.

The chatbot should be able to answer questions related to almost any academic degree or field, including Computer Science, Software Engineering, IT, AI, Data Science, Engineering, Medical, Business, Accounting, Economics, Mathematics, Physics, Chemistry, Biology, Arts, English, and other educational subjects.

Features:

Add a floating chatbot button at the bottom-right corner.

Open a clean and modern chat window when clicked.

Users can ask questions in English, Urdu, or Roman Urdu.

Give clear, accurate, easy-to-understand answers.

Explain difficult topics step-by-step with examples.

Help with definitions, concepts, formulas, programming questions, assignments, exam preparation, and general study questions.

If a question is ambiguous, ask the user for clarification.

Do not make up information when unsure; clearly say when more information or verification is needed.

Keep answers relevant to the user's question.

Support follow-up questions and maintain the conversation context.

Add quick buttons: “Ask a Question”, “Explain a Topic”, “Solve a Problem”, and “Exam Help”.

Include typing/loading animation.

Add clear chat and minimize buttons.

Make the chatbot fully responsive on mobile, tablet, and desktop.

Use a professional academic design that matches the website.

Make the interface simple, fast, and user-friendly.

Important:
The chatbot should work as a general educational assistant rather than being limited to skincare. It should answer questions from different academic degrees and subjects while keeping responses educational, safe, and easy to understand.
